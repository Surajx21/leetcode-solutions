## 📚 Approach

This repository is a **learning log and reference**, not simply a collection of answers.

For each problem, I aim to understand:

1. What is the core pattern?
2. Why does the solution work?
3. What alternatives exist?
4. What is the time complexity?
5. What is the space complexity?
6. Can the solution be improved?

> **Try solving the problem yourself before looking at the solution.**
